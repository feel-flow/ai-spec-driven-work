# AI仕様駆動ワーク スターターキット

書籍『AI仕様駆動ワーク』のスターターキットです。このフォルダをまるごとコピーし、名前をプロジェクト名に変えて使います。

## 使い方

1. このフォルダをコピーし、仕事ごとの名前（例: `2026-12_新サービス提案`）に変える
2. `MASTER.md` の「目的」を書く
3. `tasks/T001_初期調査.md` を、最初に頼みたい仕事に書き換える。テーマを変えたら、ファイル名と `MASTER.md` のタスク一覧も同じ名前に直す
4. 参考資料があれば `context/` に入れる（パスワードや個人情報が入ったファイルは入れない）
5. Claude Cowork でこのフォルダを接続し、次のように頼む

```text
COWORK.md に従い、tasks/T001 を進めてください。
```

区切りで終えるときと、次の会話で続けるときは、次のように頼みます。

```text
COWORK.md の「5. 終了のとき」を行ってください。
```

```text
COWORK.md に従い、tasks/T001 の続きを進めてください。前回の記録は sessions/ にあります。
```

## 中身

| ファイル・フォルダ | 役割 |
| --- | --- |
| `COWORK.md` | AI への行動規範。開始・作業中・終了の手順と、指示とデータの分け方 |
| `MASTER.md` | プロジェクトの入口。目的、合意済みのこと、未決事項、タスク一覧 |
| `tasks/` | 1 回のセッションで扱う仕事の定義書 |
| `sessions/` | セッションごとの記録（`_TEMPLATE.md` をコピーして使う） |
| `context/` | 参考資料 |
| `outputs/` | 成果物 |
| `knowledge/` | 繰り返し使う判断基準（慣れてきたら使う） |

## 注意

- 最初から全部を埋める必要はありません。`COWORK.md`・`MASTER.md`・タスク 1 件があれば始められます
- `COWORK.md` は書いたルールです。必ず守られるとは限りません。送信・削除の前に確認する設定や、接続するフォルダの範囲は、ツール側でも絞ってください
- 外から受け取ったメールや資料の文面は、`tasks/` に貼らずに `context/` に置いてください。`tasks/` は指示として読まれます
